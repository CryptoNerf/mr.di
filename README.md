# Mr.Di.

Перевод незнакомого английского слова прямо поверх того, что вы читаете или смотрите —
и одной клавишей в личный словарь с повторениями.

Обычно это выглядит так: встретил незнакомое слово → свернул видео → открыл переводчик →
набрал слово → вернулся обратно → потерял мысль. Mr.Di. убирает из этой цепочки всё,
кроме одного нажатия. Подсказка появляется рядом с курсором и **не забирает фокус**:
видео продолжает играть, каретка в тексте остаётся на месте.

Слово можно достать откуда угодно — даже оттуда, где текст выделить нельзя:

| Откуда | Как |
|---|---|
| Статья, PDF, код | выделить и нажать **⌥Space** |
| Видео, картинка, игра, скриншот | **⌥S** — обвести область, текст распознаётся с пикселей |
| Субтитры, строка за строкой | **⌥R** — переснять ту же область одной клавишей |
| Услышал, но не видишь | **⌥A** — расшифровка последних 15 секунд системного звука |
| Знаешь на слух, не знаешь написание | **⌥V** — сказать слово в микрофон, по-английски или по-русски |

Без сервера, без API-ключей, без подписки и без аккаунта. Всё работает на вашем компьютере.

## Установка

Нужна macOS 15 Sequoia или новее. Проверено на Apple Silicon.

### Готовое приложение

1. Скачайте **MrDi-1.0.dmg** со страницы [Releases](https://github.com/CryptoNerf/mr.di/releases).
2. Откройте образ и перетащите **MrDi** в папку «Программы».
3. Снимите карантин — одна команда в Терминале:

   ```bash
   xattr -d com.apple.quarantine /Applications/MrDi.app
   ```

4. Запустите приложение.

> ### Почему нужен шаг 3
>
> Если его пропустить, macOS скажет, что приложение **«повреждено и не может быть открыто»**.
> Оно не повреждено. Так macOS ведёт себя с любой программой, не заверенной у Apple:
> заверение стоит 99 $ в год, и я пока не могу себе этого позволить. Команда снимает
> пометку «скачано из интернета» — больше она не делает ничего.
>
> В macOS 15 Apple убрала старый обход через правый клик → «Открыть», поэтому Терминал
> сейчас самый надёжный путь. Если он вам не нравится, то же самое делается мышью:
> попробуйте открыть приложение, получите отказ, затем откройте
> **Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»**
> в появившейся там строчке.
>
> Не хотите верить команде на слово — весь код открыт, соберите приложение сами.

### Сборка из исходников

Нужен Xcode 16 или новее.

```bash
git clone https://github.com/CryptoNerf/mr.di.git
cd mr.di
./scripts/setup-signing.sh        # один раз: сертификат для подписи
./scripts/build-app.sh --install  # соберёт и положит в /Applications
```

Собранное так приложение карантином не помечается — шаг с `xattr` не нужен.

Первая команда создаёт самоподписанный сертификат «MrDi Dev». Он нужен не для галочки:
macOS привязывает выданные разрешения к подписи приложения, и без постоянного сертификата
они слетали бы после каждой пересборки. При первой подписи связка ключей один раз спросит
разрешение на использование ключа — нажмите **Always Allow**.

### Разрешения

Приложение живёт в меню-баре (иконка с шапочкой) и просит четыре разрешения. Все они
выдаются в **Системных настройках → Конфиденциальность и безопасность**:

| Разрешение | Зачем | Когда спросит |
|---|---|---|
| **Универсальный доступ** | прочитать выделенный текст в чужом приложении и перехватить ⏎/␛ при открытой подсказке | при первом запуске |
| **Запись экрана** | снимок области экрана для распознавания текста и захват системного звука | при первом **⌥S** |
| **Микрофон** | продиктовать слово голосом | при первом **⌥V** |
| **Распознавание речи** | разобрать речь на устройстве, без отправки звука куда-либо | при первом **⌥V** или **⌥A** |

После выдачи Универсального доступа и Записи экрана приложение нужно перезапустить —
macOS не подхватывает эти разрешения на лету:

```bash
pkill -x MrDi && open /Applications/MrDi.app
```

### Чтобы работало как задумано

Включите в меню-баре **«Запускать при входе»**. Незнакомое слово попадается внезапно —
к этому моменту приложение уже должно работать.

## Как пользоваться

| Клавиши | Что делает |
|---|---|
| **⌥Space** | перевести выделенное слово или фразу |
| **⌥S** | обвести область экрана — текст распознаётся с пикселей |
| **⌥R** | переснять последнюю область (для субтитров: обвели один раз, дальше только ⌥R) |
| **⌥V** | сказать слово в микрофон: зажать и говорить, либо нажать → сказать → нажать. Понимает оба языка: скажете по-русски — ответит английским словом |
| **⌥A** | расшифровка последних 15 секунд системного звука, слова в ней кликабельны |
| **⏎** | добавить слово в словарь вместе с предложением, в котором оно встретилось |
| **P** | произнести слово вслух |
| **␛** | закрыть подсказку (клик мышью тоже закрывает) |
| **⌥D** | открыть словарь |
| **␣**, **1–4** | в режиме повторения: показать перевод, затем оценить, как вспомнилось |

Пара неочевидных вещей, которые сильно экономят время:

- **⌥R для субтитров.** Обведите строку субтитров один раз — дальше на каждую новую реплику
  жмите только ⌥R, ничего обводить не нужно.
- **⌥A вместо перемотки.** Не нужно ни ставить на паузу, ни угадывать написание: расшифровка
  показывает, что прозвучало, а нажатие на слово в ней открывает перевод с этой же фразой в контексте.
- **⌥V работает в обе стороны.** Язык называть не нужно: запись распознаётся сразу двумя
  распознавателями, английским и русским. Сказали «собака» — увидите `dog` с транскрипцией;
  в словарь при этом всё равно ляжет карточка «dog → собака», словарь остаётся английским.
  Если язык всё же определился неверно — **⇥** переключает на вторую версию,
  диктовать заново не нужно.
- **Счётчик повторных просмотров.** Приложение помнит каждый просмотр, даже несохранённый,
  и подписывает «3-й раз» — слова, которые реально мешают вам читать, видно сразу.

## Словарь и повторения

Сохранённые слова превращаются в карточки: в окне словаря есть переключатель
**Словарь / Повторение**, приложение само решает, какое слово и когда показать.

Интервалы считает **FSRS** — тот же алгоритм, что в современном Anki. Он оценивает не
«сколько дней прошло», а два свойства памяти: стабильность и сложность, — и назначает показ
на момент, когда вероятность вспомнить падает до 90%. Новое слово с оценкой «Помню» вернётся
через 4 дня, затем через 15, 50, 149. Забытое возвращается в конце текущей сессии.

На карточке предложение-контекст показано сразу, но с закрытым словом (`•••`): так оно
вспоминается по смыслу, а не по знакомому виду строки.

Экспорт CSV из окна словаря импортируется в Anki: слово, перевод, транскрипция,
определение и контекст разложатся по полям карточки.

## Приватность

Всё, что можно сделать на устройстве, делается на устройстве:

- перевод — системный переводчик Apple, офлайн;
- распознавание текста с экрана и речи — `Vision` и `Speech`, офлайн;
- словарь и история — локальный SQLite, никакой синхронизации.

В сеть уходит ровно один запрос: транскрипция и значения слова из открытого API поверх
Wiktionary. Результат навсегда оседает в локальном кэше, поэтому одно и то же слово ходит
в интернет **один раз**. Без интернета приложение работает целиком, просто без словарной статьи.

Прослушивание системного звука **выключено по умолчанию** и включается вручную в меню-баре.
Пока оно включено, последние 30 секунд звука лежат в кольцевом буфере в оперативной памяти:
на диск ничего не пишется и никуда не отправляется.

## Как устроено

| Слой | Что делает | Файл |
|---|---|---|
| Хоткеи | глобальные сочетания через Carbon, с событием отпускания для «зажал и говори» | `Sources/MrDi/Hotkey.swift` |
| Захват текста | Accessibility API + фолбэк через ⌘C с восстановлением буфера обмена | `Sources/MrDi/SelectionCapture.swift` |
| Захват экрана | выделение области + `ScreenCaptureKit` со снимком в 2× | `Sources/MrDi/RegionSelector.swift`, `ScreenCapture.swift` |
| OCR | `Vision`, только английский — так точнее на коротких фрагментах | `Sources/MrDi/OCR.swift` |
| Системный звук | кольцевой буфер 30 с, ничего не пишется на диск | `Sources/MrDi/SystemAudioRecorder.swift`, `AudioRing.swift` |
| Речь и микрофон | `SFSpeechRecognizer` на устройстве, два языка параллельно, живая расшифровка | `Sources/MrDi/Transcriber.swift`, `MicRecorder.swift` |
| Перехват клавиш | CGEvent tap, глотает только ⏎/␛/P при открытой подсказке | `Sources/MrDi/KeyInterceptor.swift` |
| Нормализация | `NLTagger`: словарная форма и часть речи | `Sources/MrDi/Lookup.swift` |
| Перевод | системный `Translation` framework, офлайн, оба направления | `Sources/MrDi/TranslationBridge.swift` |
| Словарная статья | транскрипция, значения и примеры, кэш навсегда | `Sources/MrDi/DictionaryService.swift` |
| Произношение | `AVSpeechSynthesizer`, офлайн | `Sources/MrDi/Speaker.swift` |
| Подсказка | `NSPanel`, который никогда не становится key-окном | `Sources/MrDi/HUDController.swift` |
| Повторение | FSRS 4.5 | `Sources/MrDi/FSRS.swift`, `ReviewView.swift` |
| Хранилище | системный SQLite, без внешних зависимостей | `Sources/MrDi/Store.swift` |
| Иконка | `icon.png` → `.icns` средствами системы | `scripts/make-icon.sh` |

Внешних зависимостей нет вообще: только системные фреймворки macOS.

База лежит в `~/Library/Application Support/MrDi/mrdi.db`.

Иконку можно поменять, положив свой `icon.png` (или `icon.svg`) в корень проекта —
следующая сборка подхватит его сама.

## Выпуск новой версии

```bash
./scripts/make-dmg.sh                                    # build/MrDi-<версия>.dmg
gh release create v1.0 build/MrDi-1.0.dmg --title "Mr.Di. 1.0"
```

Образ подписывается ad-hoc, а не сертификатом «MrDi Dev»: самоподписанный сертификат
существует только в связке ключей автора, и на чужом маке такая подпись не проходит проверку.
Ad-hoc-подпись — это просто хэши кода, она валидна везде. Версия берётся из `Resources/Info.plist`.

## Если что-то не работает

**⌥Space ничего не делает.** Проверьте Универсальный доступ и перезапустите приложение.
Если галочка стоит, а доступа нет, разрешение «залипло» — сбросьте и выдайте заново:

```bash
pkill -x MrDi
tccutil reset Accessibility com.mrdi.app
open /Applications/MrDi.app
```

**Связка ключей спрашивает разрешение при каждой сборке.** Нажмите **Always Allow**
или один раз выполните:

```bash
security set-key-partition-list -S apple-tool:,apple: -s -k ПАРОЛЬ_МАКА ~/Library/Keychains/login.keychain-db
```

Если отклонить диалог, сборка не развалится: подпись откатится на ad-hoc, но разрешения
после этого придётся выдать заново.

**«Приложение повреждено и не может быть открыто».** Это карантин, а не поломка.
Выполните `xattr -d com.apple.quarantine /Applications/MrDi.app` — подробности выше,
в разделе про установку.

**Первый перевод долго думает.** Система один раз докачивает русский языковой пакет.
Дальше перевод мгновенный и офлайн.

**OCR путает буквы.** Снимок делается в двойном разрешении, но на очень мелком шрифте
помогает обвести область с запасом — вместе с соседними словами.

**Удалить всё.** `rm -rf /Applications/MrDi.app ~/Library/Application\ Support/MrDi`
и `security delete-certificate -c "MrDi Dev"`.
